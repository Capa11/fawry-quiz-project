How to test the API

Choose the correct server, open an endpoint, press Try it out, fill the request, then press Execute.

For protected endpoints, call POST /api/auth/public/signin, copy the returned JWT, then use Authorize.

Swagger UI sends the JWT in the Authorization: Bearer <token> header.

For an error response, use the Example Value selector to inspect every named error scenario. Frontends must branch on the stable error code, not the English message.

The error path is the request URI that failed. It is diagnostic context, not a frontend redirect URL.
